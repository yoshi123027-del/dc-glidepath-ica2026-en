# Validation of the Four Mean–Variance Solution Concepts

This directory contains the validation code corresponding to Appendix A.3 of the paper. Table 5.1 of van Staden, Dang and Forsyth (2021) reports numerical examples not only for PCMV but also for DOMV, cTCMV, and dTCMV. All four solution concepts are therefore included in the external validation. The constrained monthly implementation developed for this paper is then validated separately through independent forward propagation and grid-based diagnostics.

| Model | External reproduction | Internal audit of this paper's implementation |
| --- | --- | --- |
| PCMV | Recompute the published distributional statistics from the reflected-lognormal closed form and verify them by a two-million-path Monte Carlo simulation | Backward–forward moments, mass conservation, and boundary quantities |
| DOMV | Recompute the published statistics from the normal terminal distribution and the coefficient corresponding to the target mean, with an additional Monte Carlo check | Backward–forward moments, mass conservation, and boundary quantities |
| cTCMV | Recompute the published statistics from the normal terminal distribution and the coefficient corresponding to the target mean, with an additional Monte Carlo check | Backward–forward moments, mass conservation, and boundary quantities |
| dTCMV | Identify the lognormal terminal distribution from the published mean and standard deviation, recompute the remaining statistics, and verify them by Monte Carlo simulation | Baseline-grid moment and mass audits, plus tail stability for `x_max=900` versus `x_max=2100` |

## Scope of the dTCMV external validation

The reference paper establishes that dTCMV terminal wealth is lognormally distributed, but Table 5.1 does not report the numerical solution path of the integral equation that determines the time-varying coefficient. The external validation therefore uses the published mean and standard deviation as distribution-identifying anchors and independently recomputes the median, skewness, excess kurtosis, VaR, CVaR, shortfall probabilities, and conditional means.

This exercise reconstructs the published terminal distribution. It does **not** claim to reproduce the unpublished time-varying coefficient path. The control path generated by this repository is assessed separately through the internal solver diagnostics.

## Running the validation

Run the following commands from the repository root:

```bash
python validation/external_validation_vanstaden2021_all_mv.py
python validation/run_all_validations.py
```

`run_all_validations.py` also reruns the external reproduction and stores the principal outputs in `results/validation/`. In the current reference version, the configured checks pass for PCMV, DOMV, cTCMV, and dTCMV. If any check fails, the script exits with a non-zero status.

The detailed CSV outputs contain the reported values, tolerances, and audit decisions and should be treated as the numerical source of record.
