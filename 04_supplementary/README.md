# Supplementary analyses

The paper's supplementary sensitivity analyses use the same adopted parameterization but retain the original screening design (`N_t = 80`) for directional robustness checks.

Covered sensitivities include:

- safe terminal asset / `D_T`
- risk-free rate `r`
- risky-asset expected return `mu`
- risky-asset volatility `sigma`
- contribution profile

These are robustness screens, not replacements for the monthly (`N_t = 480`) main results. Rebuild them through the adopted reference algorithms and the tested parameter-only workflow.
