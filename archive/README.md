# Archive

This area preserves **historical, exploratory, and superseded material** for auditability. It is not the authoritative source for the current ICA2026 results.

| Folder | Contents |
|---|---|
| [`papers/`](papers/) | Earlier manuscript versions and their figures and supporting materials |
| [`legacy_v5/`](legacy_v5/) | Legacy calculations, code, audit records, and manuscript material |
| [`old_results/`](old_results/) | Superseded grids and numerical outputs not used for the current reported results |
| [`exploratory/`](exploratory/) | Exploratory analyses, manifests, retired automation assets, and historical reference material |

Archived Japanese manuscripts, revision notes, figures, and reports are intentionally retained in their original language as historical source artifacts. Their presence here does **not** indicate that they are current English deliverables.

For the current research companion, use:

- [Top-level research overview](../README.md)
- [Manuscript context](../paper/README.md)
- [Current saved results](../results/current/)
- [Current validation and robustness checks](../results/validation/)
- [Numerical implementation and reproduction guide](../recalibration/)

In particular, there is no `paper/current/` directory in this English repository; the manuscript itself is not distributed here.
