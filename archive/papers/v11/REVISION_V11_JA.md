# v11：四方策の比較を中心とした論文の再構成

今回の改訂は、v5由来の内容・数値・図を保ちながら、論文の主張の優先順位をそろえる編集である。新たな最適化計算や、レビュワーが担当する数値解の妥当性検証は追加していない。

## 一貫させた論旨

主たる貢献は「共通のDC投資制約の下で、四つの平均–分散方策を比較し、意思決定原理の違いが加入者の運用成果にどう現れるかを示す」こととした。

初期比較では期待終価をそろえる。途中の条件付き評価では時点と残高をそろえ、本文の具体例はcTCMVとdTCMVに焦点を当てる。四方策すべてを同じ目的関数で順位付けするとは主張していない。

| 位置づけ | 内容 |
|---|---|
| 主たる貢献 | 共通条件の下での四方策の比較と、意思決定原理・運用成果の関係 |
| その比較を補う分析 | クリップによる実装近似が配分と分布に与える影響 |
| 実務上の含意 | PCMVを設計基準とし、cTCMV・DOMV・dTCMVを三つの運用上の役割に対応させる提案 |
| 将来の研究拡張 | MVS。主たる貢献や第四の運用層として扱わない |

## 主な変更

- タイトルを「確定拠出年金における四つの動的平均–分散方策の比較」に変更した。
- 要旨・序論・結論を、比較→クリップ分析→実務上の含意の順に書き直した。
- 序論にあった「三層グライドパス設計への翻訳が中心的な目的」という記述を整理した。
- 数値結果の章は四方策の分布と配分の違いから始め、クリップ評価の短い導入をその後に置いた。詳細な診断は付録を維持した。
- 三層運用の章を「比較から得られる実務上の含意」とし、採用済みの結論や独立した主貢献に見えないようにした。
- 付録のO1–O4とC1–C6も、主たる比較を支える要素・補助分析・研究拡張として整理した。
- MVS付録に残っていた「本稿の主題であるグライドパスの内生的導出」という表現を、四方策比較との関係を示す説明へ変更した。
- 数値検証の観点に関する詳しい記述を付録へ移した。数値検証自体は追加していない。
